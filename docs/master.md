# Linkord 開発マスタードキュメント

## 1. サービス概要

Linkordは、Discordユーザーのプロフィール、リアルタイムステータス、Minecraft戦績、SNSリンク、所属サーバーをひとつにまとめる、無料のプロフィール＆サーバーポータルである。

公式ドメイン：

```text
https://linkord.net
```

プロフィールURL：

```text
https://linkord.net/@username
```

サーバーURL：

```text
https://linkord.net/server/:slug
```

## 2. キャッチコピー

Discordの活動を、ひとつのプロフィールに。

## 3. サービスの目的

Linkordは、以下を実現する。

- Discordユーザーが自分の活動を紹介できる
- Minecraftの実績やリアルタイムステータスを表示できる
- Discordサーバーをプロフィールに掲載できる
- 新しいDiscordサーバーやユーザーを発見できる
- SNS、GitHub、Qiitaなどのリンクをまとめられる
- 無料でおしゃれなプロフィールを作成できる

## 4. 想定ユーザー

- Discordを日常的に使うユーザー
- Minecraftプレイヤー
- Minecraft PvPプレイヤー
- Discordサーバー運営者
- Discord Bot開発者
- 学生エンジニア
- GitHubやQiitaで活動するユーザー
- 自分のSNSや活動実績をまとめたいユーザー

## 5. 最重要コンセプト

Linkordは、以下を統合したサービスである。

- Discordプロフィール
- リアルタイムプレゼンス
- Minecraft戦績
- サーバー宣伝
- サーバーランキング
- ユーザーフォロー

## 6. 基本方針

- 基本機能は無料で提供する
- 有料プランは作らない
- プロフィールとサーバー発見機能を中心にする
- 外部APIが停止してもプロフィール本体は表示する
- 外部APIの取得失敗時に画面全体を壊さない
- ユーザーが自分のデータを削除できるようにする
- ユーザーアップロードには容量・形式・時間制限を設ける
- テーマはプリセット制にする
- カスタムCSSは提供しない
- Discord公式サービスと誤認される表現は使用しない
- 管理者による通報確認機能を用意する
- 作らない機能をAIエージェントが勝手に追加しない
- 秘密情報をソースコードに直書きしない
- 不明な仕様を推測で確定しない

## 7. 外部サービス

- Discord OAuth2：ログイン・基本ユーザー情報
- 他のOauth系
- Lanyard：Discordプレゼンス・Spotify・アクティビティ
- PlayHive API：Minecraft戦績
- GitHub CDN：サービス共通の静的アセット
- PayPay送金リンク：任意の開発支援

## 8. 現時点で作らない機能

Linkordでは、現時点で以下の機能を作らない。

- 有料プラン
- 独自チャット
- 通知システム
- プロフィール訪問者の個人履歴
- 複数Minecraftサーバーの戦績API
- カスタムCSS
- スマホアプリ
- サーバーオーナー向け広告管理
- 高度な広告配信
- フォロー通知
- コメント機能

## 9. 開発支援

Linkordは、ドメイン代、VPS代、バックアップ費用、将来的なR2やCDN費用などを、任意の開発支援によって補う。

- 支援は完全に任意
- 支援しなくても基本機能を利用できる
- 支援によって主要機能を制限しない
- 支援者には任意でSupporterバッジを付与できる
- 支援額は公開しない
- 支援者名は本人が希望した場合のみ公開する
- 支援は有料プランや機能購入ではない
- 支援リンクはPayPay送金リンクを使用する
- PayPayリンクは利用者が安全に開発者(私)に送れるように。webhookで自分専用discordサーバーに送信するつもり

表示文言：

> Linkordのドメイン代・サーバー代などの維持にご協力ください。支援は任意で、支援しなくても基本機能を利用できます。

## 11. AIエージェントへの共通ルール

- 既存仕様を勝手に変更しない
- 有料機能を追加しない
- 現時点で作らない機能を追加しない
- 外部APIに依存してプロフィール本体を壊さない
- 秘密情報をコードに直書きしない
- `.env`をGitにコミットしない
- DB変更にはマイグレーションを用意する
- 実装後は正常系・異常系の両方を確認する
- 未実装部分を実装済みとして報告しない
- 仕様変更が必要な場合は、変更内容を明記する
