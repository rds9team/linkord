## 3. Botの機能一覧

- **/up**: 
  - 実行したサーバーの Linkord 掲載順位をトップに押し上げます（Bump）。
  - 同時に、Discord サーバーの最新人数・アイコン・サーバー名を Linkord 側に自動同期します。
  - 連投防止のため、1サーバーにつき1時間のクールダウン（残り時間を Discord タイムスタンプで表示）。
- **/info**:
  - 現在のサーバーが Linkord 上でどのように掲載されているか（メンバー数・タグ・URL等）を Embed 表示。
- **/help**:
  - Linkord Bot のコマンドヘルプと公式サイト案内。

## 4. PlayHive API が動いていなかった原因と対策

- **原因**: 
  - `api.playhive.com` のエンドポイントに **Cloudflare Bot Management** が全面適用されており、外部サーバーやVPSからの通信がブロック・タイムアウトする状態でした。
- **対策**:
  - API呼び出しタイムアウトを 2.5 秒に短縮し、サイト全体の読み込み遅延を防止。
  - Minecraft のスキン頭部アイコン（MC-Heads）は Cloudflare の影響を受けず超高速に取得できるため安定表示。
  - 戦績がブロックされた場合やデータがない場合は、全 0 の不自然な数値を表示せず「PlayHive API が保護・メンテナンス中か、プレイ履歴がありません」と親切なメッセージカードにフォールバック表示。

## 5. アイコン削除機能

- **プロフィール設定**:
  - 設定画面で現在設定中のアバター画像の横に「**削除**」ボタンを追加。
- **サーバー作成**:
  - サーバーアイコンの横に「**アイコンを削除**」ボタンを追加。
- **バックエンド**:
  - 空文字で更新リクエストを受け取った際に、データベース側で `NULL` にリセットして反映。
